# Third Generation Business Centre website

1. Extract the ZIP. Open the extracted folder until you see index.html.
2. On your new GitHub repository, use Add file → Upload files. Upload the files inside the extracted folder to the repository root and commit to main.
3. In Settings → Pages, choose Deploy from a branch, then main and /(root), and save.
4. Open the live link from Settings → Pages once deployment completes.

The website images, styling and interactive script are inside index.html. The public company profile PDF and prices.csv belong beside index.html.

To preview offline, open index.html. To try prices in the quote form offline, use its file picker to select prices.csv. GitHub Pages loads it automatically.

To change estimate prices, edit the amounts in prices.csv in Excel, preserve the names and headers, save as CSV UTF-8 and upload the updated file to GitHub.
